# 英语学习知识库 · English Learning Knowledge Base

> 零基础英语学习者的网页版资料库。基于 **B 站 339 个英语教学视频 + 339 份中英双语字幕**整理，
> 全部中文讲解，**所有英文都能点一下听发音**，断网可用。

## 打开方式

**GitHub Pages（推荐，任何设备都能打开）：**
<https://chuan-sy.github.io/english-learning-kb/>

**本地：** clone / 下载后双击 `index.html`。

## 技术

纯静态站点，Vue 3 全局构建（`vendor/vue.global.prod.js`），无构建步骤、无外部依赖、无网络请求。
发音全部本地预生成 mp3。

```
index.html              页面骨架
assets/data.js          全部正文内容（8 章 44 篇）
assets/app.js           Vue 应用（路由 / 搜索 / 进度 / 主题）
assets/style.css        主样式 + 响应式断点
assets/theme.css        4 套配色
assets/audio.js         发音播放器
assets/interaction.js   互动练习
audio/                  1139 段合成音频 + 40 段音标本音
vendor/                 Vue 3.5.13
```

## 资料怎么来的

1. B 站缓存的 339 个视频 → ffmpeg 合并 MP4
2. faster-whisper（large-v3-turbo）提取中英双语字幕
3. 整理成网页 —— 全部基于视频原话，无编造内容
4. 英文发音用 Piper 离线合成；音标本音来自 IPA 官方图表（ipachart.com）

详见 [`使用说明.md`](使用说明.md)。
